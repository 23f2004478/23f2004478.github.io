Work

AI agent systems and machine learning projects. The agent platform runs on open-source Hermes Agent with human approval gates. Machine learning projects focus on NLP fine-tuning, class imbalance, and analytics dashboards.

The platform runs 39 recurring scheduled jobs across 11 agents: 10 that each own one area, plus 1 that routes my requests. Operations like sending emails, deleting data, or public git pushes pause at approval gates until I verify them.

Agent systems (6 case studies)

  • Multi-agent operations platform

    Eleven agents that hand work to each other on task cards, with a review step before anything risky. Includes hourly medic drift monitoring and janitor cleanups.

    11 AGENTS · 39 JOBS

  • Model routing and tiered compute

    One gateway on my server in front of most of my model accounts, so a failed call moves to a backup model. Claude models are called directly. Plain Python and Bash scripts perform exact calculations before any model is invoked.

    GATEWAY & FALLBACK

  • How my agents remember: five layers of memory I can read and edit

    Each agent keeps short curated notes, and a context engine (LCM-X) summarises long chats into searchable summaries while keeping the full original messages on disk.

    CHAT MEMORY

  • Reliability and security

    Encrypted nightly backups copied offsite to cloud storage and a private GitHub repository, locked-down secrets, and a written, scripted runbook to rebuild the server from scratch.

    ENCRYPTED BACKUPS

  • Finance ledger agent

    Reads my receipt emails (read-only access), turns them into ledger entries with fixed parsing rules, and nets refunds against the original order in my self-hosted Firefly III finance app.

    RULE-BASED PARSING

  • Personal LinkedIn studio

    Local drafting environment that screens technical posts against voice notes and anti-AI writing patterns. Every post is manually reviewed and published by me.

    HUMAN PUBLISHES

  • Token ledger

    Full multi-model usage accounting across 9router proxy, Hermes direct Claude, and Claude Code transcripts with prompt cache hit rates and list price USD.

    5.45 B TOKENS · 3 SOURCES

Private operational platform. Architecture, system boundaries, and verified telemetry are presented across each case study.

Machine learning & analytics projects (4 projects)

  • Smart MCQ solver (LoRA fine-tuning)

    Parameter-efficient fine-tuning of DeBERTa-v3 and RoBERTa using LoRA adapters for 5-option multiple-choice ranking. Blended in a 70:30 ensemble achieving 0.74242 MAP@3 on 500 unseen questions.

    0.74242 MAP@3

  • Comment classification

    Feature engineering over 198,000 comments across four imbalanced label classes. Engineered 10,000+ n-grams, screened tabular features, and tuned LightGBM with Optuna to reach 0.8293 F1-Macro.

    0.8293 F1-MACRO

  • Customer exit prediction

    Compared 8 classifiers on 90,000 customer records from a financial institution. Tuned a Random Forest to a validation F1 of 0.6365 (accuracy 0.8414).

    0.6365 F1

  • VC deal analytics dashboard

    Power BI deal analytics dashboard built on a 50,000-row synthetic star schema. Engineered 7 DAX measures and configured 2 AI visuals for valuation driver ranking.

    POWER BI · STAR SCHEMA
