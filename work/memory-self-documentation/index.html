Memory Tier Architecture

Design & Implementation Details

To maintain long-term consistency across agent workflows without unbounded prompt bloat, memory is stratified into three distinct layers:

  1. Episodic Vector Store: Indexes historical interactions using local embeddings, allowing semantic recall of past technical decisions.
  2. Curated Core Memory: High-signal facts and standing conventions managed under strict character caps with automated pre-modification snapshots.
  3. Autobiography Ledger & Progress Reporting: Append-only event tracking in structured JSONL paired with an automated nightly reporting daemon that sends scannable HTML status briefings.
