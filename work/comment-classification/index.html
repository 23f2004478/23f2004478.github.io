Multi-Class Imbalanced Text Classification

Engineered 10K+ n-grams and behavioral signals across 198K comments, executed a 100-trial Optuna hyperparameter study, and raised F1-Macro from 0.6221 to 0.8293.

Context Machine Learning Project
Timeline Jan 2026 to Mar 2026
Dataset 198,000 Records (4 Classes)
Stack LightGBM, Optuna, scikit-learn

The Imbalanced Classification Challenge

Online comment moderation pipelines must identify toxic and obfuscated content across multiple severity tiers. In real-world moderation datasets, clean non-toxic text dominates the distribution, while severe violations constitute small fractions of total volume.

Across a corpus of 198,000 comments partitioned into 4 classes, standard unweighted classifiers achieved high nominal accuracy by consistently predicting the majority class, while completely missing critical minority violations. The core challenge was optimizing F1-Macro to ensure equal weighting across all four severity classes.

Feature Engineering & Statistical Screening

1. Multi-Scale Feature Extraction

Engineered a dual feature matrix combining textual and metadata indicators:

  • Textual N-Grams: Extracted over 10,000 word and character n-grams (ranging from 1-grams to 5-grams) to detect misspelled, spaced-out, and obfuscated keywords.
  • Behavioral & Structural Metrics: Computed 11 tabular features including uppercase ratio, punctuation density, digit frequency, and comment length metrics.

2. Statistical Hypothesis Testing

Screened all candidate features for statistical significance against target class labels across 198K rows:

  • Applied chi-square tests of independence to validate categorical text token distributions.
  • Applied Kruskal-Wallis non-parametric tests to confirm variance in continuous metrics across target classes without assuming normal distribution.

Optuna Optimization & Threshold Calibration

1. 100-Trial Bayesian Hyperparameter Tuning

Configured an Optuna hyperparameter study tuning 10 LightGBM parameters simultaneously: learning_rate, num_leaves, max_depth, min_child_samples, subsample, colsample_bytree, reg_alpha, reg_lambda, and class weight multipliers.

Implemented Optuna's MedianPruner over 3-fold stratified cross-validation, automatically terminating 62 underperforming trials early to focus compute on promising parameter spaces.

2. Nelder-Mead Probability Threshold Tuning

Standard argmax decision rules fail when class frequencies are severely skewed. Using the Nelder-Mead simplex algorithm, I optimized probability multiplier weights post-inference, aligning decision boundaries specifically to maximize the multi-class F1-Macro score.

Verified Metrics & Performance Gains

Benchmark Metric Result Experimental Setup & Notes
Final Test F1-Macro 0.8293 Evaluated on 39.6K held-out validation rows
Baseline Logistic Regression 0.6221 Standard TF-IDF baseline with default parameters
Cross-Validation F1 0.8070 3-fold stratified CV across 158.4K training rows
Optuna Search Space 100 Trials 62 trials pruned early via MedianPruner
Total Corpus Processed 198,000 Rows Full 4-class imbalanced text dataset

Key Takeaways

  • Character n-grams capture evasion: Sub-word and character-level features are essential for catching deliberate spelling distortions designed to bypass keyword filters.
  • Early pruning saves compute: Median pruning in Optuna eliminated 62% of unpromising training runs, enabling a much broader exploration of tree depth and regularization parameters.
  • Threshold optimization yields free gains: Post-processing probability thresholds via Nelder-Mead provides substantial F1 improvements without retraining underlying models.
