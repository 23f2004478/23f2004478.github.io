Work

Memory and self-documentation

Built-in curated memory, the LCM-X context engine, append-only autobiography ledger, daily progress reports.

Built on Hermes Agent (open source, Nous Research). I did not write Hermes; many skills are third-party. I designed the partitioning, routing, guardrails, and the scripts that hold them together.

Context

An agent that forgets everything between sessions cannot build on past work. An agent that carries everything forward accumulates noise. The solution is layered memory: volatile session context, curated persistent facts, a lossless context engine that compacts long sessions into searchable summaries, and an append-only ledger for the full record.

Limits

  • The LCM-X engine summarizes long sessions; finding an old detail sometimes means searching the summary index instead of an instant recall.
  • The daily report is self-reported by the agents, not verified by an external observer.
