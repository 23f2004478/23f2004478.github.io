Work

Memory and self-documentation

Episodic vector memory, curated persistent memory, append-only autobiography ledger, daily progress reports.

Built on Hermes Agent (open source, Nous Research). I did not write Hermes; many skills are third-party. I designed the partitioning, routing, guardrails, and the scripts that hold them together.

Context

An agent that forgets everything between sessions cannot build on past work. An agent that carries everything forward accumulates noise. The solution is layered memory: volatile session context, curated persistent facts, episodic vector recall for similarity search, and an append-only ledger for the full record.

Limits

  • Episodic memory uses local embeddings; quality depends on chunking and indexing frequency.
  • The daily report is self-reported by the agents, not verified by an external observer.
