Case Study 02 • Compute Governance

Model Routing & Compute Tiers

Deterministic-first execution engine routing tasks from exact local scripts to tiered model endpoints with loopback proxy fallback and strict cost discipline.

Routing Principles

The core operating principle is deterministic execution first. Any task involving exact arithmetic, regex transformation, file searching, facts verification, or SQL querying is executed via local Python, Bash, or SQL scripts with zero LLM token consumption.

When reasoning or natural language synthesis is required, tasks pass through a local 9Router loopback proxy that resolves model aliases to available backend providers, handling rate limits and failovers transparently.

Max Tier Architectural planning, system decomposition, critical issue debugging Flagship reasoning models Reserved for high-leverage planning decisions

Compute Tier Categorization

  • Deterministic Scripts: Instantaneous local execution for math, facts checking, and data parsing.
  • Medium Tier: Fast, cost-efficient models for routine summaries, classification, and drafting.
  • High Tier: High-capability models for complex coding, multi-file refactoring, and logical synthesis.
  • Max Tier: Flagship reasoning models reserved exclusively for architecture decomposition, system planning, and blocker resolution.
