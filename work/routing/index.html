Model routing and tiered compute: local gateway with fallback resilience

One local loopback gateway in front of multiple model providers, with fallback chains and three effort tiers. Plain scripts handle deterministic computation before any model is invoked.

Gateway
9Router Local Loopback Proxy
Routing Strategy
Provider Fallback · 3 Effort Tiers (Medium / High / Max)
Core Invariant
Deterministic Scripts (Python/Bash) Precede LLM Invocations

Problem

Directly binding agent workflows to a single AI provider causes brittle failures when rate limits or upstream outages occur. Furthermore, sending basic data extraction or mechanical formatting tasks to expensive models wastes tokens and increases latency.

What I Built

  • 9Router Gateway: A local proxy sitting between agent profiles and external AI APIs, intercepting model requests and routing them through fallback provider chains.
  • Tiered Compute Offload: Tasks are categorized into three difficulty tiers: medium (mechanical refactors, formatting), high (multi-file implementation, test generation), and max (architecture planning, deep fact audits).
  • Deterministic First Rule: Exact computations (mathematical formulas, file system queries, regex extractions) must execute in native Python or Bash before passing structured context to an LLM.

Outcome

Zero agent task aborts from transient provider rate limits or token exhaustion. Deterministic scripts handle bulk data filtering locally, reducing context overhead and ensuring predictable computational behavior across all 12 profiles.

Limits

Fallback chains introduce slight latency variations when switching between upstream providers, requiring graceful timeout management.

Stack

9Router · Python · Bash · REST APIs · Linux
