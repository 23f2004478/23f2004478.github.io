Work

Model routing and tiered compute

Loopback 9Router gateway with provider fallback. Script before LLM. Effort tiers: medium, high, max.

Built on Hermes Agent (open source, Nous Research). I did not write Hermes; many skills are third-party. I designed the partitioning, routing, guardrails, and the scripts that hold them together.

Context

Every LLM call has a cost: time, compute, and distraction for expensive reasoning tasks. Using the same model for everything is wasteful. A rule-first, model-second approach runs the cheapest exact solution first and escalates only when that fails.

Architecture

How a request moves

A task arrives and the first gate is deterministic: can a script compute the exact answer? If yes, no model is called. If no, the task goes to the medium tier. If the medium model can't produce a satisfactory result, it escalates to high, then to max. All model calls pass through a loopback 9Router gateway with provider fallback, so a quota exhaustion on one provider does not stall the run.

Limits

  • No latency figures are claimed; this is a personal system with no SLA.
  • The tiering is a heuristic applied by the orchestrator, not an automated classifier.
