LinkedIn studio

Local post drafting with voice profile, humanizer pass, human publishes. Agent never posts.

Built on Hermes Agent (open source, Nous Research). I did not write Hermes; many skills are third-party. I designed the partitioning, routing, guardrails, and the scripts that hold them together.

Context

LinkedIn post drafts need a consistent voice and a humanizer pass to strip AI tells before the author reads them. The studio provides a local drafting environment: the agent drafts with a voice profile, applies the humanizer, and the human reads and publishes. The agent never posts.

Limits

  • The agent does not have access to LinkedIn. The human reads every draft before publishing.
