Reliability and security

Encrypted backup capsules, GitHub Releases offsite mirror, scripted restore, hourly health checks.

Built on Hermes Agent (open source, Nous Research). I did not write Hermes; many skills are third-party. I designed the partitioning, routing, guardrails, and the scripts that hold them together.

Context

A single-server AI platform is fragile. A disk failure or misconfigured update should be recoverable from a fresh VPS in one scripted run. The reliability design has three layers: detection (hourly health checks), backup (encrypted capsules mirrored offsite), and restore (scripted, tested procedure).

Architecture

Limits

  • No restore time is claimed; the procedure has not been tested under production load.
  • GitHub Releases is a single-provider offsite target; a GitHub outage would block offsite access.
