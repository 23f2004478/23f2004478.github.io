Case Study 05 • Financial Automation

Financial Ingestion & Reconciliation Ledger

Deterministic ingestion of digital receipts from read-only Gmail into normalized, idempotent transaction records stored in self-hosted Firefly III.

Ingestion Pipeline Architecture

The financial processing engine monitors digital invoices and payment receipts using a read-only Gmail API integration. Structured templates and deterministic regular expressions extract transaction metadata, falling back to a structured LLM schema extractor only when encountering unfamiliar email formats.

Reconciliation Integrity

Transactions are normalized and assigned deterministic hash keys to ensure idempotency. Refunds and duplicate receipt notifications are netted automatically before posting to the self-hosted Firefly III ledger instance.
