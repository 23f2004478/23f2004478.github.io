Work

Finance ledger agent

Read-only Gmail ingestion of receipts, deterministic parsers, idempotent transactions, self-hosted Firefly III.

Built on Hermes Agent (open source, Nous Research). I did not write Hermes; many skills are third-party. I designed the partitioning, routing, guardrails, and the scripts that hold them together.

Context

Financial receipts arrive as unstructured email. Manual bookkeeping is error-prone and slow. The finance ledger agent reads email receipts, parses them with deterministic code, and posts normalized transactions to a self-hosted Firefly III ledger. The LLM is called only for ambiguous text that the parser cannot classify.
