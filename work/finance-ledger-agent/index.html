Finance Ledger & Spend Ingestion Agent

An automated spend reconciliation pipeline ingesting e-commerce and utility receipts via read-only Gmail scopes, executing deterministic regex parsers, and synchronizing normalized transactions into a self-hosted Firefly III ledger.

DATA SOURCE Gmail Read-Only OAuth
LEDGER CORE Firefly III (Self-Hosted)
PARSER ENGINE Deterministic Regex + LLM Edge
IDEMPOTENCY External Transaction Hash
Private System: Personal financial accounting pipeline. Operating architecture and data normalization rules are shared below with zero financial numbers or merchant names.

Ingestion Pipeline Diagram

Engineering Highlights

Manual expense tracking suffers from friction and missing entries. This system automates ingestion while adhering to strict privacy and data consistency rules:

  • Deterministic Precision: 95%+ of incoming order formats are parsed using pure regular expressions and structural ASTs, guaranteeing zero hallucinated line items or amounts.
  • Idempotency Guarantees: Transactions generate a deterministic external ID from order numbers and timestamps, preventing duplicate ledger entries upon re-runs.
  • Refund Netting: Return transactions automatically map to their originating purchase, maintaining accurate net category totals.

Technology Stack

  • Firefly III
  • Python 3.12
  • OAuth 2.0
  • REST API
  • Docker
