Smart MCQ Solver: Parameter-Efficient Fine-Tuning with LoRA

Fine-tuning transformer architectures using Low-Rank Adaptation (LoRA) on query and value projections, combined into a 70:30 weighted ensemble for question ranking.

Context IIT Madras DL Project
Timeline May 2026 to Jul 2026
Architecture DeBERTa-v3 & RoBERTa
Framework PyTorch, PEFT, Hugging Face

Problem Statement & Formulation

Multiple-choice answer selection across complex scientific domains requires models to capture subtle semantic nuances rather than relying on surface token overlap. Given a prompt question and 5 candidate options, the objective is to rank options such that the correct answer appears in the top 3 predictions.

The primary evaluation metric was Mean Average Precision at 3 (MAP@3) over a dataset of 2,000 training questions and 500 unseen test questions. Full fine-tuning of multi-hundred-million parameter transformers presents severe compute overhead and vulnerability to catastrophic forgetting on specialized domains.

Technical Methodology & Training Pipeline

1. Parameter-Efficient Fine-Tuning with LoRA

To achieve efficient adaptation without modifying full model weights, I applied Low-Rank Adaptation (LoRA) via Hugging Face PEFT:

  • Target Modules: Injected low-rank decomposition matrices into the query and value attention projection layers (q_proj, v_proj).
  • Hyperparameters: Configured rank r = 8, scaling factor alpha = 16, and a dropout rate of 0.1 to prevent co-adaptation of adapter weights.
  • Trainable Parameter Reduction: Reduced trainable parameters to under 1% of total model capacity while retaining full base model contextual representations.

2. Multi-Architecture Training & Ensembling

Trained two distinct transformer backbones using identical LoRA configurations:

  • microsoft/deberta-v3-base: Utilizes disentangled attention and enhanced mask decoder mechanisms, providing superior syntactic understanding.
  • roberta-base: Provides strong contextual bidirectional embeddings.

Constructed a 70:30 weighted probability ensemble favoring DeBERTa-v3 while incorporating RoBERTa's probability distribution to reduce prediction variance on edge cases.

3. Experiment Tracking with Weights & Biases

Monitored training runs via Weights & Biases (W&B), tracking cross-entropy loss trajectories, validation MAP@3 curves, learning rate warmups with cosine decay, and gradient norm stability across training epochs.

Key Machine Learning Insights

  • Low-rank efficiency: LoRA adapters deliver competitive ranking accuracy on scientific multiple-choice questions while drastically cutting GPU memory requirements during training.
  • Disentangled attention advantage: DeBERTa-v3 consistently outperformed RoBERTa on scientific reasoning due to separate position and content embeddings.
  • Ensemble stability: Combining representations from different pre-training schemes smoothed output probability spikes and improved rank consistency.
