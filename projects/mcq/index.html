Fine-Tuning Architecture

Formulated multiple-choice question answering as a 5-option sequence classification ranking task across 2K questions, optimizing Mean Average Precision at 3 (MAP@3) as the official metric.

Implemented Low-Rank Adaptation (LoRA) parameter-efficient fine-tuning on two transformer architectures:

  • microsoft/deberta-v3-base: LoRA rank r=8, alpha=16, dropout 0.1 on query_proj and value_proj layers (task_type=SEQ_CLS).
  • roberta-base: LoRA rank r=8, alpha=16, dropout 0.1 on query and value projection layers.

Ensemble & Evaluation

Combined predicted class probabilities using a weighted 70:30 ensemble (70% DeBERTa-v3 + 30% RoBERTa). Training dynamics were logged via Weights & Biases, achieving a verified 0.74242 MAP@3 on Kaggle's public leaderboard across 500 unseen test questions.
