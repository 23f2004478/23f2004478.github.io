Data Preprocessing & Imbalance Handling

Missing numerical values in account balances and credit scores were imputed using an IterativeImputer, while categorical features were handled via mode imputation.

Eight distinct classifiers were benchmarked: AdaBoost (0.4604), Decision Tree (0.5033), Logistic Regression (0.5509), Extra Trees (0.5736), Random Forest (0.5796), Gradient Boosting (0.6006), XGBoost (0.6277), and LightGBM (0.6277).

Metric Judgement & Tuning

Top candidate models were tuned using RandomizedSearchCV against F1 score. Tuned Random Forest achieved the winning validation F1 score of 0.6365 (Accuracy 0.8414, Precision 0.6181, Recall 0.6561, Best CV F1 0.6456), outperforming tuned LightGBM (0.6334) and tuned XGBoost (0.6309).

Imbalance Analysis: While raw accuracy reached 0.8414, it flatters a skewed distribution where non-churn predominates. F1 score (0.6365) and Recall (0.6561) provide the honest measure of churn retention efficacy.
