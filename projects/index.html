Machine learning and analytics projects

Every project is evaluated on the metric that genuinely reflects its objective: F1-Macro for severe class imbalance, MAP@3 for candidate ranking, and validation F1 for customer retention. High accuracy on skewed data is misleading; we lead with the metrics that measure real performance.

Featured projects

  • Smart MCQ solver (LoRA fine-tuning)

    Parameter-efficient fine-tuning of DeBERTa-v3 and RoBERTa using LoRA adapters for 5-option multiple-choice ranking. Blended in a 70:30 ensemble achieving 0.74242 MAP@3 on 500 unseen questions.

    0.74242 MAP@3

  • Comment classification

    Feature engineering over 198,000 comments across four imbalanced label classes. Engineered 10,000+ n-grams, screened tabular features with chi-square and Kruskal-Wallis, and tuned LightGBM with Optuna to reach 0.8293 F1-Macro.

    0.8293 F1-MACRO

  • Customer exit prediction

    Benchmarked 8 classifiers on 90,000 banking customer records with severe class imbalance. Evaluated imputation strategies and tuned Random Forest to reach a validation F1 of 0.6365 and accuracy of 0.8414.

    0.6365 F1

  • VC deal analytics dashboard

    Power BI deal analytics dashboard built on a 50,000-row synthetic star schema. Engineered 7 DAX measures and configured 2 AI visuals (Key Influencers and Decomposition Tree) for valuation driver ranking.

    POWER BI · STAR SCHEMA

More projects, in brief

  • Virtual AI Teaching Assistant (RAG Pipeline)

    Built a Retrieval-Augmented Generation (RAG) assistant using OpenAI embeddings and SQLite vector store. Chunky course materials and retrieved top-k relevant context via cosine similarity with FastAPI endpoints.

    2025 · RAG · FASTAPI

  • HR Attrition Dashboard (Power BI)

    Two-page Power BI dashboard with 12 DAX measures analyzing workforce turnover, like-for-like prior-quarter hiring patterns, and retention drivers.

    2026 · POWER BI · DAX

  • Consumer Spend Segmentation (K-means++)

    Segmented 62 consumer survey respondents across personal care and dining spend dimensions using K-means++ (0.540 silhouette score). Feature selection experiments proved a 2-dimension model outranked 3-dimension sets.

    2024 · K-MEANS++ · PYTHON

  • Migration Determinants Regression Study (R)

    Specified a 5-regressor OLS model in R across 28 Indian states analyzing out-migration. Found per-capita income (p=0.002), poverty (p=0.025), and unemployment (p=0.018) statistically significant at 5%.

    2025 · R · OLS REGRESSION

  • Influencer and Sponsor Matching Platform (Flask)

    Full-stack web application connecting content creators and commercial sponsors using Flask, SQLite, and Jinja2 with 10+ analytical tracking dashboards and role-based access controls.

    2024 · FLASK · FULL-STACK
