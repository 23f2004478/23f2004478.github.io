VC deal analytics dashboard: Power BI on a synthetic star schema

A 3-page Power BI deal analytics dashboard engineered on a 50,000-row synthetic star schema, with 7 custom DAX measures and 2 native AI visuals for valuation driver analysis.

Deliverable
3-Page Power BI Dashboard · 8 Charts · 4 KPI Cards
Data Modeling
Star Schema · 50,000-Row Fact Table · 4 Dimensions
DAX Measures
7 Custom Measures (YoY Growth, CALCULATE Filters, DIVIDE Guards)
AI Visuals
Key Influencers · Decomposition Tree

Context and Synthetic Data Note

I built this for the DWDV elective at IIM Ranchi (Term IV). The underlying dataset was generated synthetically in Python using deterministic random seeds to simulate multi-stage venture capital deal activity, sector deployment, and exit valuations.

Star Schema Data Modeling

The schema centres on a 50,000-row table of deals, linked to 4 lookup tables in a clean star schema.

DAX Engineering and AI Visuals

Authored 7 DAX measures implementing time-intelligence (YoY growth via SAMEPERIODLASTYEAR), dynamic multi-filter aggregations using CALCULATE, and mathematical safety guards using DIVIDE.

Configured two native Power BI AI visuals to assist exploratory analysis: the Key Influencers visual to rank factors driving high exit multiples, and the Decomposition Tree visual to allow interactive breakdown of invested capital across sectors and geographies.

Limits

The dataset is entirely synthetic and designed for dashboard architecture demonstration, not market analysis.

Stack

Microsoft Power BI · DAX · PowerQuery · Python · Star Schema Modeling
