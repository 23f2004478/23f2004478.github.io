Venture Capital Deal Analytics Dashboard

Star schema data model in Python and Power BI across 50,000 synthetic deal records, authoring 7 DAX measures, 3 dashboard pages, and AI decomposition tree visuals.

Modelling Scope & Architecture

Developed as part of the IIM Ranchi Data Warehousing and Data Visualisation curriculum (Term IV). Engineered a clean dimensional star schema in Python and Power BI over 50,000 synthetic deal records connecting a central FactDeals table to DimCompanies, DimInvestors, DimSectors, and DimDate.

DAX Calculations & Visuals

Authored 7 core DAX measures incorporating time-intelligence (SAMEPERIODLASTYEAR for YoY deal pacing), context filtering with CALCULATE, and mathematical safety guards with DIVIDE.

Configured 3 analytical report pages with 8 charts, 4 KPI cards, and two advanced Power BI AI visuals: Key Influencers to identify top drivers of valuation multiples, and a Decomposition Tree to break down invested capital by sector vertical.

Note: This project is framed strictly as a dimensional modelling and visualisation exercise on synthetic data.
