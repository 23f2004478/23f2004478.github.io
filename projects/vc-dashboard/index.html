Context

IIM Ranchi Data Warehousing and Data Visualization (DWDV) elective. Task: design a star schema, populate it with synthetic data, build a Power BI dashboard with DAX measures, and present findings. The dataset was generated with NumPy (random seed 42); MOIC values are literally np.random.uniform(3.0, 15.0). No real venture capital data.

What I built

  • Star schema in Python: 50,000-row fact table, 4 dimension tables.
  • 3-page Power BI dashboard: 8 charts, 4 KPI cards on exit and valuation.
  • 7 DAX measures: YoY growth via SAMEPERIODLASTYEAR, CALCULATE filters, DIVIDE guards.
  • 2 Power BI AI visuals: Key Influencers and Decomposition Tree to rank MOIC and capital drivers.

Limits

  • Dataset is synthetic. No real deal data, no real exits, no market insight.
  • Dashboard has 3 pages (not 4). Smart Narrative, anomaly detection, forecasting, and bookmarks mentioned in the report are not present in the .pbix file.
  • The 25%-weight group project component is not claimed.
