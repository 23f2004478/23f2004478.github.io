6-Stage Multi-Agent Architecture

From voice or chat prompt to deterministic execution, approval gates, and tracked delivery.

01 Depth 0

Any-Device Ingest

Voice prompts via FreeFlow (Mac) and Dictate (Android), Discord and Telegram command channels, Tailscale WireGuard mesh, and Termius mobile SSH.

02 Router

Central Triage & Router

Intent parsing, domain boundary validation, dependency gating, and asynchronous Kanban task dispatch across specialist agent queues.

03 Depth 1

12 Specialized Agents

Dedicated specialist agents hosted 24/7 on Azure Cloud VPS with isolated workspaces, persistent memory, and scoped toolsets.

04 Depth 2

Compute & Egress

Dynamic model tiering across Claude Opus, Sonnet 5.5, and Gemini 3.7 Flash, with rotating egress through Tor and Cloudflare WARP.

05 waits for me

The Human Gate

Strict safety invariant: destructive actions like git pushes, outbound emails, deletions, and ledger writes pause for my explicit approval.

06 Depth 3

Delivery & Ledger Sync

Async completion to Google Tasks, private GitHub repositories, Firefly III accounting ledger, and instant chat notifications.

Six agent systems, one person signing off

I run a personal multi-agent platform on open-source Hermes Agent. I did not write Hermes. My part is the design: which agent owns what, how work moves between them, and where it has to stop for me.

A router and 11 domain agents each own one area. Work moves on kanban cards, from an orchestrator to a worker and then to a review gate. A medic agent checks for drift every hour. A janitor suggests cleanups and acts only after I say yes.

This site went through the same flow, and the review gate caught defects before anything went live.

  1. 11 Sep 2026 Started on a MacBook (M1 Max) inside a Linux VM, with a local model gateway, local embeddings and episodic memory (used only in this laptop phase, 11 to 20 Sep 2026), MCP via OAuth 2.0 PKCE.
  2. 20 Sep 2026 Moved the whole runtime to an Azure server on Ubuntu 24.04, run by systemd.
  3. Since then Daily progress reports with per-agent time telemetry, MECE multi-agent partitioning, encrypted backup capsules, and an autobiography ledger.
