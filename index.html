From a voice note on my phone to a finished, tracked result, with anything I would regret waiting for my approval: sends, deletes and public pushes.

01 Input

Any-Device Ingest

I dictate on my phone or Mac (FreeFlow, Dictate) and send it on Discord or Telegram. I sometimes SSH in via Termius from my phone or laptop over Tailscale.

02 Router

Central Triage & Router

A router agent reads the request, checks which domain owns it, and files a kanban task for the right specialist.

10 specialist agents

Six agent systems, one person signing off

I run a personal multi-agent platform on open-source Hermes Agent. I did not write Hermes. My part is the design: which agent owns what, how work moves between them, and where it has to stop for me.

A router and 10 domain agents each own one area. Work moves on kanban cards, from an orchestrator to a worker and then to a review gate. A medic agent checks for drift every hour. A janitor suggests cleanups and acts only after I say yes.

This site went through the same flow. The review step caught defects, and a separate fact audit caught more.

  1. 11 Sep 2026 Started on my MacBook inside a Linux virtual machine, with models and memory running locally (only during this laptop phase, 11 to 20 Sep 2026) and secure logins to outside tools.
  2. 20 Sep 2026 Moved the whole runtime to an Azure server on Ubuntu 24.04, run by systemd.
  3. Since then Daily progress reports showing time per agent, clean non-overlapping jobs for each agent, encrypted backups, and a running log of what the system has done.
