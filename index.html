Six agent systems, one person signing off

I run a personal multi-agent platform on open-source Hermes Agent. I did not write Hermes. My part is the design: which profile owns what, how work moves between them, and where it has to stop for me.

A router and 11 domain profiles each own one area. Work moves on kanban cards, from an orchestrator to a worker and then to a review gate. A medic profile checks for drift every hour. A janitor suggests cleanups and acts only after I say yes.

This site went through the same flow, and the review gate caught defects before anything went live.

  1. 11 Sep 2026 Started on a MacBook (M1 Max) inside a Linux VM, with a local model gateway, local embeddings and episodic memory (used only in this laptop phase, 11 to 20 Sep 2026), MCP via OAuth 2.0 PKCE.
  2. 20 Sep 2026 Moved the whole runtime to an Azure server on Ubuntu 24.04, run by systemd.
  3. Since then Daily progress reports with per-profile time telemetry, MECE multi-profile partitioning, encrypted backup capsules, and an autobiography ledger.
