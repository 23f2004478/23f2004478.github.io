Moved the agents from laptop to cloud server

20 Sep 2026 · Shipped · Infrastructure

What changed

Hermes Agent, the open-source framework my agents run on, moved from a Linux virtual machine on my MacBook (M1 Max) to a cloud server running Ubuntu. The model gateway (9Router, which sends each request to a model) and the provider sync now run as system services on that server.

Why it matters

The agents keep working when the laptop is closed. Scheduled jobs and the daily progress report no longer depend on my machine being awake.

Result

Gateway and sync were deployed as services on 21 Sep 2026.

Lesson

The date of this move rests on a billing record and a boot log rather than my memory. I now log milestones to an append-only ledger with an ID and cite that ID when I write about them.
