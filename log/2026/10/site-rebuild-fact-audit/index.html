Rebuilt this site; fact audit checked every number

3 Oct 2026 · Shipped · Site

What changed

This site went from a game-themed page to a professional portfolio. A planning model wrote the spec, a builder agent worked through it from a task board, and served screenshots were reviewed before it went live. The diagrams and charts are now 14 inline SVG figures, each with a data table.

Why it matters

Every number on the site now traces to a source line: 380 numbers in all. A script measures diagram text on 23 pages at 3 screen widths. Rows under the 13px floor went from 18 to 0.

Result

Merged and live on 3 Oct 2026, with 0 failing rows on the text size check.

Lesson

An earlier draft contained claims that did not match my records, and the fact audit caught them before release. An automated review also passed a build with visible defects, so every release now gets a separate check of the rendered pages before it goes live.
